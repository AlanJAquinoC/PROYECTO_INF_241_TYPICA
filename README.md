# Typica Café — Sitio Web del Proyecto ADOO 2026

Sitio web interactivo desarrollado para la presentación y defensa del proyecto **«Análisis y Diseño de un Sistema de Gestión de Comandas, Estaciones de Producción y Control de Insumos para la Operativa de Typica Café en la ciudad de La Paz»** (Carrera de Informática, UMSA).

## 📁 Estructura Interna

* `index.html`: Estructura semántica completa con secciones de Introducción, Antecedentes, Problema, Árbol Causal, Objetivos, Delimitación, Metodología, DFD interactivo, Modelos UML, Diagrama de Gantt y Equipo.
* `assets/Proyecto_ADOO_Typica_Cafe_Parte_1_v2.pdf`: Informe oficial del proyecto listo para descarga directa.
* `assets/css/style.css`: Estilos de diseño, paleta tipográfica y esquemas de respuesta para móviles y tablets.
* `assets/js/main.js`: Lógica de tabs para los diagramas DFD, animaciones de barras en el Gantt y scroll suave.
* `assets/diagramas/`: Archivos exportados de draw.io listos para renderizado SVG embebido interactivo.
* `assets/images/`: Logotipos de la UMSA, Carrera de Informática y Typica Café, junto a fotografías patrimoniales de las sucursales.

---

## 🌐 Cómo Abrir

Puedes abrir `index.html` en cualquier navegador web moderno (Google Chrome, Firefox, Safari o Microsoft Edge).  
Para pruebas locales con servidor HTTP:
```bash
python3 -m http.server 8080
```
Luego visita: `http://localhost:8080`
